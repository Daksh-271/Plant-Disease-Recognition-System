# Plant Disease Recognition

Deep Learning based web application for identifying plant diseases using CNN.

## Features
- Upload plant leaf image
- Predict disease
- Disease confidence score
- Streamlit-based web app

## Tech Stack
- Python
- TensorFlow
- OpenCV
- Streamlit
